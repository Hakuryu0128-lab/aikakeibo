# AI家計簿 静的版 v2

ビルド、npm、GitHub Actionsは不要です。5ファイルをリポジトリ直下へ上書きしてください。

## 更新方法
1. ZIPを展開します。
2. 中の5ファイルをGitHubのリポジトリ直下へアップロードし、同名ファイルを上書きします。
3. Pagesは Deploy from a branch / main / root のままで変更不要です。
4. 公開後、ブラウザを再読み込みします。PWA版が古い場合はブラウザで一度開いてから再起動します。

## v2追加機能
- 帳簿検索、収入・支出絞り込み
- 高額・低確信度・自動登録OFF時の登録前確認
- AI記憶の一覧、追加、削除
- 明細修正からMistake Memoryを作成
- AIプロンプトへの記憶反映
- CSV出力
- JSON完全バックアップで記憶も保存
- レシート原画質送信
